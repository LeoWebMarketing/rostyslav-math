# Klasno - Design System

Brand: **Класно / Klasno** (klasno.online). Learning platform for Ukrainian primary-school kids.
The brand name is theme-neutral; the current visual theme is **cartoon dinosaurs / jungle adventure**
(prehistoric-park mood). Theme-specific assets live under `public/theme/dino/` so the skin can change
without touching the brand.

Legacy exception: **2 клас > Математика** is the original Squid Game app, kept as-is in its own
isolated entry (`/g2/`). It does not follow this document.

## Mood
Friendly cartoon dinosaurs, lush jungle, ferns, volcano on the horizon, warm sunlight, explorer gear
(hat, map, compass, binoculars). Adventure, never scary: dinosaurs are big-eyed and kind, even the T-rex.
**No** Jurassic Park name, logo, skeleton-in-circle emblem, amber mosquito, gates or any Universal mark.

Subject colors: Математика = `--sun-400`, Українська = `--berry-500`, Англійська = `--sky-400`.
Contrast: body text >= 4.5:1, large text/icons >= 3:1. Never encode correct/wrong by color alone -
always icon + text too.

## Typography
- Font: **Nunito** (full Cyrillic), self-hosted via `@fontsource/nunito` (works offline in the PWA).
- Weights: 600 body, 800 headings/buttons.
- Sizes (mobile-first): body 18px, exercise prompt 22-26px, headings 28-32px, button 20px.
  Kids read slowly - never below 16px anywhere.

## Layout and responsiveness (mandatory)
Primary devices are a **tablet and a phone** held by a child. Mobile-first.
- Breakpoints tested: **375** (phone), **768** (tablet portrait), **1024** (tablet landscape), **1440** (desktop).
- Touch targets >= **56px** high in lessons, >= 48px elsewhere; 12px min gap between targets.
- No hover-only affordances. Every interaction works with one finger.
- Both orientations. Lesson content max-width 720px, centred on large screens.
- The on-screen keyboard must not cover the typing input or the Check button (`visualViewport`).
- Safe-area insets respected (`env(safe-area-inset-*)`).
- No horizontal page scroll at any breakpoint.

## Components
- **Buttons**: rounded 16px, 3D bottom edge (4px darker shadow) that compresses on press, Duolingo-like.
- **Option cards**: sand surface, 2px sand-300 border, selected = sky border, correct = leaf, wrong = lava.
- **Feedback sheet**: slides up from bottom after Check; green (correct) or red (wrong) with the right
  answer shown; big Continue button.
- **Progress bar**: rounded, leaf fill, top of lesson, with a small running dino at the fill edge.
- **Mascot**: **Дино** (name chosen by Roman 2026-09-23) - a cute green baby T-rex with an explorer hat and a pencil behind the ear, the Duo of Klasno. Appears across the whole site: grade picker greeting, section map, lesson feedback (cheer on correct, gentle oops on wrong), end screen, streak, empty states, loading, 404. Poses: hello, thinking, cheer, oops, sleep (more added as needed, always the same character).

## Motion
Short and bouncy (150-300ms, ease-out-back). Respect `prefers-reduced-motion`. Vibration on wrong
answer on supported devices (existing util).

## Assets
All raster art is generated by Codex (`codex-subscription`, native image_generation) from prompts
kept in `docs/asset-prompts.md`. WebP for photos/illustrations, PNG with transparency for mascot/icons.
