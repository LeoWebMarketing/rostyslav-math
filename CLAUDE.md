# Класно.online (klasno.online) - learning platform for kids

Project name: **Класно.online** (renamed from "rostyslav-math" by Roman 2026-09-23). Repo, directory and session slug are still `rostyslav-math` until the rename is done. Owner: Roman.
Rebuilt 2026-09-23 from the Squid Game math app. Plan: `docs/PLAN.md`. Design: `DESIGN.md`.
Image prompts: `docs/asset-prompts.md`.

## Structure
**Клас > Предмет > Розділ > Урок.**
- **2 клас > Математика** = the original Squid Game app, kept as-is in `legacy/`, served at `/g2/`.
  Do not restyle or refactor it unless Roman asks.
- **3 клас** and later = new Klasno app, cartoon-dinosaur theme, subjects Математика,
  Українська мова, Англійська мова.

## Content workflow
Roman sends screenshots/photos of the current school topic. The session decides the section,
invents the exercises and adds them as data under `content/grade-N/<subject>/`. Mechanics are
Duolingo's: choose from options, match pairs, type the answer, build a sentence from word chips,
fill the gap. Every new section passes the content schema test before deploy.
**All delegated work (code, content, images) goes to `sol`; `luna` is not used on this project** (Roman 2026-09-23). Content in particular (Roman 2026-09-23 - a wrong answer taught to a
child is not cheap to notice). The orchestrator reads every exercise before it ships.

## Hard rules
- **Mobile and tablet first, mandatory.** Rostyslav uses a tablet and a phone; most users will too.
  Every UI change is checked at 375, 768, 1024 and 1440 px, touch targets >= 48px (56px in lessons),
  no hover-only interactions, no horizontal scroll, on-screen keyboard never covers input or Check.
- Theme art lives in `public/theme/<theme>/`; the brand stays theme-neutral so the skin can change.
- All raster images are generated by Codex (`codex-subscription`, image_generation) from prompts
  in `docs/asset-prompts.md`; reviewed before shipping. No film trademarks (nothing from Jurassic Park).
- Child privacy: kids have only a nickname and avatar; parent Google account is the only personal
  data; no third-party analytics or trackers.

## Stack
React 18 + Vite + TypeScript + Tailwind + React Router; Cloudflare Worker (static assets + Hono API);
D1 `klasno-db`; Google OAuth (parent) + child profiles; guest mode without login.

## Deploy
Cloudflare account from `~/.claude/secrets/cloudflare-api.env` (see CREDENTIALS.md; never print it).
`npm run build && npx wrangler deploy`; D1: `npx wrangler d1 migrations apply klasno-db --remote`.
Domains `klasno.online` + `www` (registrar Cloudflare). Rollback: git tag `pre-klasno`, and the old
Pages project `rostyslav-math` (rostyslav-math.pages.dev) still serves commit e74aedf.
